# Joseph Kiragu — Personal Portfolio

A professional personal portfolio website showcasing my background, skills, projects, and contact information.

## Built With
- HTML5
- CSS3
- JavaScript
- PHP
- MySQL / MariaDB

## Features
- Responsive portfolio homepage
- About and professional background
- Services and technical skills
- Projects showcase
- Contact form with server-side validation
- Secure database interaction using PDO
- CSRF protection and honeypot spam protection

## Project Structure
- `index.php` — Homepage
- `about.php` — About page
- `services.php` — Services page
- `projects.php` — Projects page
- `contact.php` — Contact page
- `includes/` — Shared website components
- `assets/` — CSS, JavaScript, and images
